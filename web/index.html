GVBASIC 模擬器

GVBASIC 程式的瀏覽器模擬器。選一個資料夾，在選單裡挑 .BAS 執行；程式存取的資料檔（.DAT）以該程式所在的資料夾為準。

a 小寫

選單：↑↓ 選擇、Enter 開啟／執行、← 或 Esc 回上層、F1 新增、F2 刪除、F4 修改程式（F3 查找沒有功能）；選到 .txt 時 Enter 轉成 BAS、Shift+Enter 試跑（不存檔）。
編輯畫面：方向鍵移動、Enter 換行（自動補下一個行號）、Backspace／Delete 刪字、Insert 切換插入／覆蓋；Esc 結束編輯並儲存：輸入檔名後按 Enter 存檔；F2 放棄修改直接離開（有改動時會先確認）。
程式執行中：數字鍵 1–9 對應機器上的 b n m / g h j / t y u，? 或「幫助」鍵為求助鍵（按鍵碼 25）；F1–F4 是按鍵碼 28–31；PageUp／PageDown 是翻頁鍵；字母永遠是小寫碼。鍵盤預設「直接輸入」，不受系統輸入法（注音等）影響；要打中文，按狀態列的「輸入：直接」或鍵盤上的「輸入法」鍵切到中文輸入法。螢幕上的「數字鍵」切換後，字母鍵會打出鍵上標的數字。

資料夾


      


      

        
已安裝的機器碼映像

        

        

        
映像只對放著它的資料夾（含子資料夾）裡的程式生效，那些程式會在「大陸機種」上跑：螢幕 RAM 位址、字集（GBK）、分頁視窗都跟著改變，程式裡的 CALL 直接進入映像裡的機器碼。同一個資料夾只能有一個映像（再裝一個會取代它）；不同資料夾可以各有自己的映像。映像只存在你的瀏覽器裡，不會上傳。

        
「安裝」就是真機上把大型 BIN 裝進快閃（真機第一次執行時顯示「裝入中…」）；有些說明書稱「植入」。程式存進快閃的存檔（例如遊戲的「Flash 存檔」）會寫在這份映像的複本裡，也留在這個瀏覽器；「重新安裝」會把它還原成原檔，存檔就沒了。

      


      

        
執行速度與聲音

        

          
          
          
          
          
          
          
        

        
真機的 BASIC 很慢，很多程式用 FOR I=1 TO 1500:NEXT I 當延遲、用迴圈圈數計反應時間。不限速時這些會在瞬間跑完。BASIC 速度是估計值（每秒執行的語句數），可隨時調整。CALL 進去的機器碼另外用「機器碼速度」限速（每秒執行的指令數，也是估計值，不是任何機型的真實時脈），覺得太快或太慢可以改。直接操作硬體的機器碼程式則以「幀率」為準：程式自己等計時器的旗標來同步畫面，真機的計時器週期不明，所以幀率是估計值，可以改。BAS 程式裡的中文是 Big5（台灣機種）還是 GBK（大陸機種），預設從文字自動判斷，判斷錯了（亂碼）可以在這裡指定。

      


      

        
裝置時鐘

        

        
程式用 PEEK(1015) 讀取「小時」（已實測確認；1016–1021 依序是分、秒、年、月、日、星期，取電腦的時間）。可在這裡指定時段來測試。

      


      

        
說明

        
BAS 是程式，DAT 是資料檔：程式用 OPEN "名稱" 時會自動補上 .DAT，並在程式所在的資料夾裡讀寫。

        
在 Chrome / Edge 選擇資料夾後，存檔會直接寫回實體資料夾。其他瀏覽器只能讀取，程式寫出的 DAT 暫存在瀏覽器裡，可用「下載」取出。

        
機器內建的圖形字（Big5 FA40 以後：花色、箭頭、房子、圖示）有真機的點陣，編號有兩種（見「圖形字編號」，預設依程式自動判斷）；對不上圖的碼顯示成帶框的十六進位碼小方塊。

        
讀「原始按鍵值」（鍵盤掃描 RAM：8 個位元組，按下的鍵把自己的那一位清成 0）的程式用的是機器的鍵盤矩陣，每個鍵都有固定的位置。矩陣從哪個位址開始因機型而異，「鍵盤矩陣」可以選：從 $BC 起、或從 $BF 起；選「自動」時，程式裡有用 PEEK(191)…PEEK(198) 這類固定位址就當從 $BF 起，否則當從 $BC 起。程式的按鍵對不上時，換另一個試試。
