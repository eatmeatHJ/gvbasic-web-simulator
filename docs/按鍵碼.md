# INKEY$ 的按鍵碼

在 NC3000 的真韌體上（用本專案的仿真跑官方映像，寫 `A$=INKEY$` 的程式逐鍵按，印出 `ASC(A$)` 與 `LEN(A$)`）量到的：**每個鍵都是一個字元，`ASC` 就是下表的碼**（不是「`CHR$(0)` 加第二碼」的兩字元形式）。只記事實，不含韌體資料。

| 鍵 | 碼 | 備註 |
|---|---|---|
| 字母 | 97–122（小寫） | 不管大小寫鍵、Shift 或 Caps Lock，`INKEY$` 一律是小寫碼；按了大小寫鍵再按 `a` 還是 97 |
| Enter | 13 | |
| 空白 | 32 | |
| ↑ ↓ → ← | 20 21 22 23 | 右是 22、左是 23 |
| 跳出（Esc） | 27 | |
| 求助 | 25 | 網頁上的「幫助」鍵、`?` |
| 輸入法鍵 | 26 | 在 `INPUT` 行裡它切換輸入法，不回傳；`INKEY$` 才收得到 |
| 大小寫鍵 | 18 | 本身是一個碼，不改變字母的碼 |
| F1 F2 F3 F4 | 28 29 30 31 | 機身標示：插入、刪除、查找、修改。`INPUT` 行裡 F2（29）刪一個字，和 Backspace 一樣 |
| 另外兩個鍵 | 14、19 | 翻頁鍵。哪個是上一頁、哪個是下一頁沒有量到：網頁照一支程式的用法暫定 19 = 上一頁（和 ↑ 同向加）、14 = 下一頁（和 ↓ 同向減） |
| 0 . % & ' | 48 46 37 38 39 | 其他符號走輸入法的符號表，不是獨立的鍵 |
| 數字 1–9 | b n m / g h j / t y u 的碼 | 數字疊在字母鍵上，沒有獨立的數字碼 |

沒有鍵會產生 16 和 17。機身第一排的系統鍵（PDA、計算、時間、英漢、AHD、劍橋等）按下去會離開 BASIC，不會有 `INKEY$` 碼（只試了其中一顆）。

## 網頁上怎麼對應

- 電腦鍵盤 F1–F4 送 28–31；`?` 和螢幕上的「幫助」送 25；PageUp／PageDown 送 19／14；Backspace 送 29。
- 螢幕上有 F1 新增、F2 刪除、F3 查找、F4 修改（在檔案選單裡 F1／F2／F4 照舊是新增、刪除、修改，F3 沒有功能；程式執行中它們就是 28–31）、輸入法（26）、大小寫（18）、▲ 頁（19）、▼ 頁（14）。
- 裝了引擎映像的程式，F4 仍然當原始掃描值（選單鍵）用。
- **輸入法**：鍵盤預設「直接輸入」，接收按鍵的隱藏欄位是密碼欄，瀏覽器不會在上面啟動系統輸入法（注音等），所以每個鍵都是原樣的鍵。要打中文：按狀態列的「輸入：直接」、或螢幕上的「輸入法」鍵（`INPUT` 進行中）切到「中文輸入法」，這時用系統的輸入法打字，組好的字在確認時送出。
- **大小寫**：`INPUT` 進行中，狀態列顯示電腦現在是「a 小寫」還是「A 大寫」（跟著 Caps Lock）；程式用 `INKEY$` 讀鍵時字母永遠是小寫碼，不受影響。

## 別處看到的另一份表

有人整理過的另一份 NC3000 鍵碼表（兩字元形式、左右鍵 22 左 23 右、網路 14、名片 15、計算 16、時鐘 17、上一頁 18、下一頁 19、Tab 25、發音 26、求助是 27）和上面量到的在好幾處不符（單字元、右 22 左 23、18 是大小寫鍵、16 和 17 沒有鍵、25 是求助、26 是輸入法、27 是跳出、F1–F4 沒列），來源也查不到（`fancyblock/GVBASIC` 倉庫的文件只有語法與功能歸類，`INKEY$` 一行「读键值」，沒有鍵碼表），所以沒有採用。
