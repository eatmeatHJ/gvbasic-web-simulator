# 官方轉換程式「GVBASIC 轉換程序 v2.0」與 token 表

## 它是什麼、哪裡找

- 金遠見（GGV）當年提供的 PC 端工具，檔名 **`BasToTxt.exe`**。官方頁面 `www.ggv.com.cn/360update/basic.html`（2002 年存檔）的說明：用文字編輯器寫程式存成 `*.txt`，用它轉成 GVBASIC 專用格式（`.bas`），再用 HotLink 下載到文曲星；也能把別人的 `.bas` 轉成 txt 來讀。
- 官網已關閉，只剩 Wayback Machine 的存檔：`http://ggv.com.cn:80/file/pc1000/game/gvtools/BasToTxt.exe`（2001-05-31 的捕捉，索引上標 8,871 位元組（推測是壓縮後的存檔大小）；下載下來的檔案實際是 28,672 位元組）。
- 注意：Wayback 目錄 `www.ggv.com.cn/download/gvbasic/gvbasic.zip` 是「GVBASIC 使用指南壓縮包」（文件），**不是**這個程式。

## 我們怎麼用它

只**靜態讀取**，沒有執行過，檔案也不放進這個專案。

它是 32 位元 Windows 程式（MFC 4.2，2001-04 編譯），沒有加殼。`.rdata`／`.data` 裡有一張關鍵字表：

- `.data` 檔案位移 `0x5020`–`0x51D8`：110 個指標，依序指向 `END`、`FOR`、`NEXT`……`MID$`，最後一個指標指向 `END_TOK`（結尾標記）。
- token 位元組 = `0x80` + 表中的順序。這個規則用我們原本從真實程式確認的 87 個編號檢查：**83 個完全相符**，不符的 4 個（`9B`、`9D`、`A0`、`A1`）原本就標為推測或未知。
- 表中 `+ - * / ^ AND OR > = <`（`C9`–`D2`）也在其中，運算子與子句字（`TO`、`THEN`、`ELSE`、`STEP`、`AT`……）和語句用同一套編號。

`tools/gvb_tokens.json` 現在就是這張表（110 筆）。表裡的順序如下，供查閱：

```
80 END   FOR   NEXT  DATA  INPUT DEL   DIM   READ
88 SWAP  TRACE NOTRACE POP  LET   GOTO  RUN   IF
90 RESTORE GOSUB RETURN REM STOP  ON    DEF   POKE
98 PRINT CONT  LIST  CLEAR NEW   TEXT  GRAPH SYSTEM
A0 NORMAL INVERSE FLASH PLAY BEEP INKEY$ LOAD SAVE
A8 KILL  FILES OPEN  CLOSE WRITE FIELD GET   PUT
B0 LSET  RSET  AUTO  LOCATE DRAW LINE  BOX   CIRCLE
B8 ELLIPSE CLS EDIT  WHILE WEND  CALL  RENAME COPY
C0 TAB   TO    FN    SPC   THEN  ELSE  AT    NOT
C8 STEP  +  -  *  /  ^  AND  OR
D0 >  =  <  SGN  INT  ABS  POS  SQR
D8 RND   LOG   EXP   COS   SIN   TAN   ATN   PEEK
E0 LEN   STR$  VAL   ASC   MKS$  MKI$  CVS$  CVI$
E8 LOF   EOF   CHR$  LEFT$ RIGHT$ MID$
```

## 這次因此改正的事

- `9B` 是 `CLEAR`（我們原本猜成 `TEXT`），`9D` 才是 `TEXT`，`A0` 是 `NORMAL`，`A1` 是 `INVERSE`。範例程式裡的 `TEXT:GOTO 10`、`TEXT:DIM A%(6,6)` 其實是 `CLEAR:GOTO 10`、`CLEAR:DIM …`。
- 因此新增了 `CLEAR`、`POP`、`MKI$`、`CVI$`、`MKS$`、`CVS$`；`CLEAR` 之前被錯當成切換文字模式，變數不會被清掉。
- txt→bas 不再因為「不知道記號碼」而拒絕這些關鍵字。

## 還沒做 / 沒驗證

- 隨機檔語句（`FIELD`、`GET`、`PUT`、`LSET`、`RSET`、`LOF`）原本只有 token 沒有實作，現在已做（行為照 arucil，見 README）。
- 這張表是 2001 年版的 v2.0，涵蓋 PC1000／CC800 時代的關鍵字。後來機種若有新增關鍵字，這張表不會有。
- `CLEAR` 的行為手冊沒寫，照 arucil 的實作（清變數、陣列、`DEF FN`、堆疊、關檔、DATA 指標歸零）；`MKS$`／`CVS$` 的 5 位元組格式也照 arucil（來回轉換一定一致，但位元組是否與真機相同沒驗證）。
